# Sariel's Tools

A collection of free web-based tools designed to help LEGO builders.

## Technical requirements

The tools are built on PHP + JS, with Bootstrap Shards used for the front-end. They will run on pretty much any PHP server.

## List of tools

- **Angles Chart** (angles.sariel.pl) - available in /angles. Lists angles that can be achieved using single LEGO pieces, includes Bricklink links for the pieces.
- **Bricksafe Thumbnail Helper** (bs.sariel.pl) – available in /bricksafethumbs. Generates easy-to-use BBCode to include in your post to create a thumbnail gallery from a selected Bricksafe page. You can choose from several thumbnail and image sizes.
- **Brickshelf Stats** (stats.sariel.pl) – available in /bsstats. A statistics tool for your Brickshelf gallery.
- **Brickshelf Thumbnail Helper** (thumbs.sariel.pl) – available in /bsthumbs. Generates easy-to-use BBCode to include in your post to create a thumbnail gallery from a selected Brickshelf page.
- **Colors Checker** (colors.sariel.pl) – available in /colorchecker. Checks for shared common colors between up to 6 various LEGO pieces.
- **Gear Ratio Calculator** (gears.sariel.pl) – available in /ratios. Calculates final ratio of multiple pairs of gears, shows theoretical output for selected motor and lists available gears combinations for a given spacing.
- **MOC Manager** (mocs.sariel.pl) – available in /mocmanager. Allows creating and sorting a detailed list of your projects.
- **Model Scaler** (scaler.sariel.pl) – available in /scaler. Allows to calculate dimensions of your model from a blueprint of the original object.
- **Monorail Network Planner** (monorail.sariel.pl) – available in /mnp. Drag & drop tool for designing Monorail track layouts.
- **Motors Stats** (motors.sariel.pl) – available in /motors. Detailed statistics of LEGO motors in a sortable, filterable list + motors toplists in several categories.
- **Pulley Ratio Calculator** (pulleys.sariel.pl) – available in /pratios. Calculates final ratio of multiple pairs of pulleys.
- **Town Parcel Planner** (town.sariel.pl) – available in /makieter. Drag & drop tool for designing town parcels layouts.
- **Unit Converter** (studs.sariel.pl) – available in /studs. Converts between multiple units, including studs, milimeters, inches, bricks, stacked plates and track links.
- **Wheels Chart** (wheels.sariel.pl) – available in /wheels. Lists LEGO wheels with their dimensions, weights, subparts, available rim/tire combinations and Bricklink links.
